# Privacy Policy — YouTube Auto Subscribe

_Last updated: July 3, 2026_

YouTube Auto Subscribe is a Chrome extension that helps you migrate your own YouTube subscriptions and playlists from one account to another using CSV files exported via Google Takeout.

## Data Collection

**This extension does not collect, store, transmit, or sell any user data.**

- The CSV files you select are read locally in your browser and processed entirely in memory. They are never uploaded anywhere.
- The extension makes no network requests to any server operated by the developer or any third party. The only pages it interacts with are the YouTube pages open in your own browser, using your existing logged-in session.
- No analytics, tracking, or telemetry of any kind is included.
- No personal information, browsing history, credentials, or user activity is recorded.

## Permissions

- **activeTab** — used to operate on the YouTube tab you are viewing when you start an import.
- **Host permission for `https://www.youtube.com/*`** — used to run the content script that performs the subscribe / save-to-playlist actions you request.

These permissions are used solely to perform the actions you explicitly initiate from the extension popup.

## Changes

If this policy ever changes, the updated version will be published at this URL and the extension's store listing will be updated accordingly.
